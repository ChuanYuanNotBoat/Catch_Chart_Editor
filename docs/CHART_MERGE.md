# 谱面合并

入口：**文件 → 合并谱面…**。窗口独立于主编辑器，可继续操作 CCE；再次点击菜单会显示同一个窗口。

1. **导入谱面 / 谱面包**支持一次选择多个 `.mc`、`.mcz`、`.zip`，也可以反复追加。**从谱面库选择**可选择本地歌曲文件夹，扫描其中全部难度。导入包只解压到独立临时目录，不改写来源谱面或资源。
2. 在上方列表多选难度，点击**添加选中项**，或双击单个难度。下方列表按顺序合并；可上移、下移、移除，也可以重复加入同一个谱面。
3. 选择下方一段后，分别设置倍速、变调、淡入、淡出及到下一段的间隔。统计显示普通音符/Rain 数量、倍速后的 BPM 范围、有效时长、首尾音符的合并时间。Rain 以尾点计算结束。
4. 可填写标题、艺术家、制谱者、难度，选择背景和封面；图片路径可直接清空。默认使用第一首的歌曲信息及图片。
5. 点击**合并**。完成后点击**导出 MCZ…**保存可导入 Malody 的包，或点击**在 CCE 中预览**直接载入工程并按来源分图层。

导出、预览、任务取消均不关闭窗口或清空参数。修改参数后需重新合并；旧预览已经导入的工程与资源独立保留。手动关闭只隐藏窗口；同次运行重新打开仍保留配置。当前不保存跨应用重启的合并配置。

## 时间和音频规则

- 倍速范围 0.25–4；BPM 同步乘以倍速，delay/音频偏移同步除以倍速。勾选**变速时改变音调**使用重采样；不勾选使用立体声共用对齐的 WSOLA 保调伸缩。较大倍速下可能听到伸缩处理痕迹。
- 间隔精确表示“上一段最后一个可玩音符（包括 Rain 尾点）→ 下一段首个可玩音符”的秒数，支持 0；最后一段无后续间隔。过渡区使用衔接 BPM，以便保留段内 BPM 及音符原有分度，而不将谱面吸附到近似时间。
- 两段间各保留最多半个间隔的尾音/前奏，其余部分静音。首段保留完整前奏，末段保留完整尾音；音频短于音符范围时补静音。淡入淡出只作用于这些前奏/尾音，最长不超过其实际长度，避免削弱可玩音符覆盖的音乐。
- 来源 BGM 的起点、offset 与音量参与混音。额外 Sound 音效先按其时间与音量混入，再统一变速；输出只写一个合并 BGM 引用。若混音峰值超过满幅，整段输出统一降低音量。
- 输出统一为 44.1 kHz 立体声 OGG Vorbis，最长 30 分钟。解码、伸缩与编码在后台执行，支持取消；包导入/导出完成前也可继续操作主编辑器。
- 只接受 Catch（`meta.mode = 3`）且含可玩音符、有效 BPM、可找到主音频的谱面。缺失的附加音效或图片在合并时报告错误。非法拍点/BPM、负 delay 等输入会被拒绝。

## CCE 预览

预览按段建立图层，重复使用同一个来源也会产生不同图层。合并音频放在首段图层中；可通过现有图层工具单独显示、锁定和编辑各段。预览导入前沿用 CCE 的未保存变更提示。

普通谱面保留合并后的 BPM 和分度。CCE 的内部 BPM 模型暂不支持 delay；含 delay 时仅预览工程改用等时的连续 120 BPM 拍轴，音符、Rain 尾点与音频时间一致。原始 MCZ 仍保留段内 BPM/delay、音符自定义字段及有效区间内的 effect；超出该段首尾音符范围的 effect 不进入合并结果。CCE 本身不显示的 effect 或自定义字段仍以原始导出包为准。

预览工程保存在应用数据目录 `merged-charts/<唯一目录>/merged.cceproj`，资源内嵌并经现有工程缓存载入。调整或关闭合并窗口不会使已导入工程失去资源；可通过工程保存/另存功能管理预览结果。

## 代码和回归

- `src/merge/ChartMerger.*`：只读来源解析、逐段时间规划、原始 MC JSON 合并。
- `src/merge/MergeAudio.*`：Qt 解码、重采样/WSOLA、裁剪/包络与混音。
- `src/merge/MergeExport.*`：MC/OGG 与按段图层工程生成。
- `src/ui/dialogs/ChartMergeDialog.*`：非模态列表、参数、后台任务、导出与预览入口。
- `ChartMergeTests`：输入保护、变速与音调、含 delay/offset 的精确衔接（含零间隔）、Rain、MCZ 往返、图层工程、取消原子性与窗口保留。
