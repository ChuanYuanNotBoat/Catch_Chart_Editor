AutoTiming 自动节拍检测模块技术文档

1. 引言

AutoTiming 是一个用于音频信号自动节拍/速度（BPM）检测与起始点检测的软件模块。它从原始 PCM 音频数据中提取音乐节奏特征，估计出每分钟拍数（BPM）、节拍相位偏移、拍号以及节拍细分，同时可输出所有检测到的起始点时间戳。该模块采用多子带能量分析、自相关和统计回归等经典信号处理技术，对多种音乐风格具有鲁棒性，尤其适用于节奏明显的音乐（如电子舞曲、流行音乐）。

本文档面向算法集成与维护人员，详细描述 AutoTiming 的算法流程、各步骤原理及模块接口，但不公开内部调优参数的具体数值。

---

2. 模块概述

AutoTiming 的核心功能：

· BPM 检测：从音频中估计每分钟拍数。
· 相位偏移估计：计算为了使节拍对齐到时间零点需要延迟音频的时间。
· 拍号与细分估计：识别每小节拍数（如 4/4 拍的分子）和每拍细分份数（如每拍二等分或三等分）。
· 起始点检测：独立于 BPM 检测，返回音频中能量突变的时刻。

模块支持常见的 PCM 编码格式（如 16-bit、24-bit 整数和 32-bit 浮点）以及多种采样率（具体数值由接口约定，通常覆盖常见音频工程采样率）。内部算法统一将特征采样率转换到固定低采样率（例如 1 kHz）进行分析，以降低计算复杂度并聚焦于节奏频段。

3. 输入输出规格

3.1 输入

参数 类型 说明
buffer const char* 原始 PCM 字节流
size uint32_t 字节数
format int 采样格式（由枚举定义，对应不同位深/浮点）
sampleRate int 音频采样率（Hz），需为模块支持值
channel int 声道数（交错存储）

3.2 输出

detect 返回结构体：

字段 类型 说明
bpm double 经过对齐（snap）后的 BPM 值；检测失败时为 0
rawBpm double 未经对齐的原始 BPM 估计
rawBpmUncertainty double 原始 BPM 估计的不确定度（标准差）
signature unsigned 拍号分子（每小节拍数），默认 1
division unsigned 节拍细分分母（每拍被几等分），默认 1
offset double 为了使节拍对齐到零时刻需要延迟音频的毫秒数

detectOnset 返回 std::vector<double>，每个元素为起始点时间戳（秒）。

4. 算法流程总览

```
原始 PCM 数据
   │
   ├─ 解码与单声道混合
   │
   ├─ 特征提取（多子带能量包络 → 降采样 → 边缘检测）
   │        ↓
   │   1 kHz 起始强度信号
   │
   ├─ BPM 估计（自相关 → 峰值检测 → 谐波序列回归 → 置信度评估）
   │        ↓
   │   原始 BPM、不确定度、拍号、细分
   │
   ├─ BPM 对齐（可选，基于有理数网格）
   │
   └─ 相位偏移估计（周期堆叠 → 峰值定位 → 群延迟补偿）
            ↓
        最终结果
```

5. 详细模块描述

5.1 PCM 解码与单声道混合

输入缓冲区包含交错声道的 PCM 样本。模块首先根据格式标识解析每个样本的位宽（如 16、24 或 32 位），并将多声道数据平均混合为单声道浮点数组。混合采用算术平均，对每种格式使用适当的缩放因子将整数样本归一化到约 [-1, 1] 范围。

要点：

· 支持小端字节序。
· 单声道混合降低后续计算量并消除声道间相位差影响。
· 对长度非法的数据抛出异常，保证输入完整性。

5.2 特征提取

特征提取将音频转换为适合节拍检测的 起始强度包络（onset strength envelope），采样率统一降为 1 kHz（即数组索引对应毫秒）。

5.2.1 子带分解

音频信号首先通过一组带通滤波器分解为多个子带。不同频段对节奏感知的贡献不同，例如：

· 低频段包含底鼓、贝斯等强节奏乐器；
· 中频段包含军鼓、人声等；
· 高频段包含镲片、打击乐瞬态。

模块采用预先设计的级联二阶节（biquad）滤波器，覆盖低通、带通和高通组合。滤波器系数根据输入采样率离线计算，保证不同采样率下频率响应一致。

实现：

· 对每个子带，使用 filterSos 在时域进行 IIR 滤波。
· 子带数量、频率边界和滤波器阶数均经调优确定，未公开具体数值。

5.2.2 能量包络计算

对每个子带的时域信号进行平方运算，得到瞬时能量包络。平方操作强调大幅度变化，并丢弃相位信息。

5.2.3 瞬态增强

仅对最低频段额外应用一个瞬态增强滤波器，该滤波器具有快速上升、缓慢衰减的特性，模拟打击乐器的包络形状。此步骤可突出低频打击声（如底鼓）的起始时刻，提高节奏清晰度。

5.2.4 非线性压缩与加权累加

对每个子带的能量包络进行非线性压缩，使用近似对数压缩，将大动态范围映射到有限区间，避免能量过大的频段淹没其他信息。压缩前基于近似中位数估计噪声底，并计算归一化增益。

压缩后的信号按预设权重累加到全局能量包络中。各子带权重根据其对节奏感知的重要性分配，通常低频和高频稍高，中频略低。

此外，由于不同子带滤波器引入的群延迟不同，在累加前对每个子带进行样本级延迟补偿，保证时间对齐。

5.2.5 降采样

累加后的能量包络首先通过一个抗混叠低通滤波器，然后采用最近邻插值（或简单抽样）降采样到 1 kHz。降采样前的低通滤波器截止频率低于降采样后奈奎斯特频率，以避免混叠。

5.2.6 边缘检测

降采样后的信号通过一个 奇对称边缘检测滤波器，用于提取能量上升沿，抑制持续能量。实现上采用正反向滤波相减构造零相位差分滤波器：

1. 将信号复制并时间反转。
2. 对原信号和反转信号分别应用同一滤波器。
3. 将反转信号的滤波结果再次反转并与原滤波结果相减。

最终输出即为起始强度包络，其峰值对应可能的节拍起始位置，且无额外相位偏移。

---

5.3 BPM 估计

BPM 估计从起始强度包络中提取周期性，确定拍周期长度。

5.3.1 自相关计算

自相关衡量信号在不同滞后下的相似度。对于节奏信号，自相关在滞后等于拍周期及其整数倍处会出现峰值。模块使用 FFT 加速自相关计算，输出长度约为输入特征长度的一半。为避免 FFT 长度超限，对过长信号进行截断。

5.3.2 峰值检测

在自相关序列的合理滞后范围内（例如 16 ms 至数秒）搜索局部极大值。峰值条件包括：

· 相关值必须为正；
· 在 ±16 ms 邻域内严格最大。

所有满足条件的峰值位置被记录为候选周期。

5.3.3 谐波序列搜索

对于每个候选峰值，将其视为基频周期，然后沿整数倍滞后向前搜索谐波峰。每个谐波位置允许一定时间容差（如 ±10 ms）。若在容差内找到实际峰值，则记录其亚采样精度位置（通过抛物线插值），并参与线性回归。回归模型为：

```
实际滞后 ≈ k * 周期
```

其中 k 为谐波阶数。通过最小二乘拟合得到更准确的周期估计。

同时计算所有谐波峰值的平均相关强度。一个可靠的拍周期通常具有较高且一致的谐波平均强度。算法筛选满足以下条件的候选：

· 谐波数量足够多；
· 覆盖足够的滞后范围（例如至少前半段）；
· 平均相关强度不低于基频峰值的一定比例。

5.3.4 周期选择与最大 BPM 限制

在多个候选周期中，算法跟踪平均相关强度的变化趋势。当某个候选的平均强度显著高于历史最佳（例如超过一定倍数）时，认为从细分周期跨越到了真实拍周期，将其标记为当前最优估计。

为避免将半拍或更短细分误判为拍，算法设置最大 BPM 上限。若初步周期对应 BPM 超过上限，则在候选周期中寻找更长、且与当前周期成整数倍的周期，并更新估计。

5.3.5 拍号与细分估计

· 拍号（signature）：在最优周期对应的候选之后，寻找与其成整数倍（倍数大于 2）的较长候选周期，该倍数即为每小节拍数。
· 节拍细分（division）：在最优周期之前，寻找与其成整数倍关系的较短候选周期，该倍数即为每拍的细分份数。

若未找到，则默认均为 1。

5.3.6 全局回归精化与置信度

使用选定的基频周期作为起点，在完整自相关范围内再次搜索谐波峰值，进行全局线性回归，得到更稳定的周期估计。回归同时提供残差标准差，用于评估周期一致性。

由回归斜率计算 BPM：

```
BPM = 60000 / 周期(ms)
```

BPM 不确定度由回归残差和样本数量推算，并考虑自相关峰值误差的非独立性（近似 f^-2 噪声），乘以修正因子。

置信度判断：

· 若有效谐波数量过少（例如 < 4），则视为失败；
· 若周期残差过大或 BPM 相对不确定度过高，则标记低置信度；
· 若存在缺失谐波或残差超过中等阈值，则返回一般置信度；
· 否则返回高置信度。

返回值编码置信度：负数表示失败，正数表示成功但精度不同，零表示最佳。

---

5.4 BPM 对齐（Snap）

原始 BPM 估计可能存在随机误差，且实际音乐 BPM 常接近常见数值（如 120、128 等）。模块提供可选的对齐步骤，将 BPM 吸附到预设的有理数网格上。

对齐表格由多行 {分母, 置信倍数} 组成，表示：若当前 BPM 与最近 1/分母 的整数倍（即 BPM 的分母分点）的偏差小于不确定度的某倍数，则将其四舍五入到该分点。表格从宽松到严格排列，优先对齐到整数，再考虑半整数、三分之一等。只有高置信度结果才进行对齐；低置信度结果保留原始值。

5.5 相位偏移估计

在获得可靠 BPM 后，需要确定节拍在时间轴上的相位。

1. 周期堆叠：将起始强度信号按拍长（60000/BPM 毫秒）等间隔分割，并将各段叠加，形成一个平均周期模板。模板峰值位置对应节拍相位。
2. 峰值定位：在模板中寻找最大值，使用抛物线插值获得亚毫秒精度偏移。
3. 群延迟补偿：边缘检测滤波器引入固定群延迟（约 1–2 ms），需从偏移中扣除。

最终偏移转换为“延迟音频使节拍对齐到零时刻”的量，输出范围在 (0, 拍长] 内。

5.6 起始点检测

独立接口 detectOnset 复用特征提取结果，直接对起始强度包络进行峰值搜索。

· 设定局部窗口（如 ±30 ms）和绝对阈值。
· 对每个窗口中心，若其值大于阈值且严格大于邻域内所有值，则视为起始点。
· 返回所有起始点时间（秒）。

该方法简单快速，适用于需要原始 onset 位置的场景，但精度略低于 BPM 检测中的相位估计。

6. 参数与配置

模块内部包含大量调优参数，均未公开具体数值。这些参数包括但不限于：

· 子带数量、频率边界、滤波器阶数与系数；
· 子带权重与延迟补偿量；
· 降采样目标采样率；
· 边缘检测滤波器系数与群延迟；
· 自相关峰值检测的窗口大小与最小滞后；
· 谐波序列搜索的容差、最小谐波数、覆盖范围要求；
· 平均相关强度筛选阈值与跃迁检测倍数；
· 最大 BPM 限制；
· BPM 对齐表格及置信倍数；
· 偏移估计中的峰值搜索边界与延迟补偿；
· 置信度判定阈值。

这些参数通过离线实验和音乐数据集标定，对算法性能至关重要。若需调整，应在充分测试后进行。

7. 性能与限制

7.1 性能

· 特征提取、自相关等主要计算均利用 FFT 和 SIMD 指令加速。
· 降采样至 1 kHz 后，后续 BPM 估计的计算量大幅降低。
· 对于典型 3–5 分钟音频，检测时间在毫秒至秒级，可满足实时或准实时需求。

7.2 限制

· 音乐类型依赖：算法假设节奏相对稳定，对自由速度（rubato）或剧烈变速的音乐表现较差。
· 采样率支持有限：仅支持预设的几种采样率，其他采样率需额外设计滤波器系数。
· 声道混合：简单平均可能丢失立体声中的节奏信息。
· 置信度：在弱节奏或无打击乐的音乐中可能检测失败或返回低置信度。
· 偏移精度：偏移估计依赖于 BPM 准确性，若 BPM 误差较大，偏移也会受影响。

8. 使用示例

```cpp
// 假设已有音频数据指针 data，长度 size，采样率 44100，立体声
AutoTiming::Result res = AutoTiming::detect(
    data, size, kFmodSoundFormatPcm16, 44100, 2);
if (res.bpm > 0) {
    printf("BPM: %.2f\n", res.bpm);
    printf("Offset: %.2f ms\n", res.offset);
    printf("Signature: %u/%u\n", res.signature, res.division);
} else {
    printf("BPM detection failed\n");
}

// 获取所有起始点
std::vector<double> onsets = AutoTiming::detectOnset(
    data, size, kFmodSoundFormatPcm16, 44100, 2);
for (double t : onsets) {
    printf("Onset at %.3f s\n", t);
}
```

9. 结论

AutoTiming 模块实现了一套完整的自动节拍检测流水线，涵盖多子带能量分析、起始强度提取、自相关周期估计、置信度评估和相位对齐。算法设计充分考虑了实时性、鲁棒性和准确性，并通过大量参数调优适应常见音乐类型。本文档描述了算法逻辑和模块接口，未公开内部参数细节，以保护核心技术。集成方可根据公开接口和流程描述进行开发与调试。
