### 播放与音频

- **重构**：主音频启用低延迟播放提示，并在可配置后端关闭高开销的变速音高补偿；播放时钟等待媒体位置真实推进后再开始外推，切换倍速时保持时间连续。
- **重构**：音频异步加载改为可取消的代次状态机，精确管理媒体状态与错误连接，避免快速切歌时旧回调污染当前加载结果。
- **修复**：设备输出延迟按当前播放倍速换算到媒体时间，避免低倍速下校正量被成倍放大。
- **修复**：非 ASCII 音频路径的临时副本保留原扩展名，并在复制前移除临时占位文件，修复此类路径实际始终复制失败的问题。
- **优化**：Note 音改由统一高精度播放时钟调度，不再依赖稀疏的媒体位置回调；使用预加载多 voice 播放池，降低触发延迟并避免密集音符被 stop/play 丢弃。
- **优化**：主编辑区播放帧改用 BPM 二分缓存直接换算拍点，移除每 tick 的高成本分数逼近；选中索引、Note 描边设置和 Hyperfruit 结果不再逐帧扫描或复制整谱数据。
- **优化**：扩大滚动网格缓存复用区间并仅在显式失效时读取渲染设置；实时预览播放刷新限制在约 33 FPS，隐藏时停止请求绘制，优先保障主画布帧时间。
- **优化**：播放帧脉冲改用绝对纳秒截止点调度，以 16/17 ms、11/12 ms 和 8/9 ms 交替贴合 60/90/120 FPS，避免整数毫秒循环造成超额绘制和长期节拍漂移。
- **优化**：主画布回归顶层窗口统一的 backing store 合成，避免独立原生子窗口表面与主窗口错开提交所产生的画面割裂和抽动。
- **优化**：主编辑区播放脉冲改由窗口 UpdateRequest 驱动，在平台支持时贴合显示器垂直刷新；画布隐藏时自动回退到高精度定时器，跨屏和刷新率变化会即时重建节拍。
- **优化**：播放帧率的“不限制”档改为明确跟随当前显示器刷新率，新安装默认使用该档；显式 60/90/120 FPS 仍可用于限制绘制负载。
- **优化**：播放卡顿探针关闭时跳过视觉抖动指标计算和高频采样调用，启用诊断时仍保留完整指标。

### 原生曲线编辑器

- **重构**：Note Chain Assist 完成内部 C++ 原生化；旧 `builtin.note_chain_assist` Python 插件不再初始化或启动外部进程。
- **重构**：统一 chart-space 曲线数据、画布命中检测、锚点排序插入、默认控制柄、贝塞尔/折线采样及非单调拍点归一化。
- **新增**：支持整曲线与右键目标段提交、follow/fixed 分段密度、音符拖拽/粘贴吸附、锚点/曲线段/音符框选、实时连接命中，以及曲线样式导入导出。
- **新增**：V3 曲线 sidecar 完整保留曲线、节点、分组、连接、形状、密度和扩展元数据，并兼容旧 Python `anchors`、handle 和 `links` 数据。
- **修复**：曲线 sidecar 使用工作副本路径并事务式切谱，保存采用 CAS 与原子写入；损坏文件不会覆盖内存状态或后续保存目标。
- **修复**：曲线编辑接入主程序统一撤销时间线；修正音符选择同步、粘贴基准拍点、模式切换和重复启用时撤销历史丢失等问题。
- **修复**：主窗口级 `Delete` 快捷键优先转发给原生曲线选择，锚点和曲线段可在画布未独占焦点时直接删除。
- **优化**：曲线模式的鼠标移动不再逐帧序列化整张谱面的 Note 上下文，并避免重复设置系统光标，消除大谱面下的严重 hover 卡顿。
- **优化**：将含义不清的顶部密度列表改为当前“生成音符间隔”，区分跟随 Time Division、固定分度和混合选择；右键入口同步改名。
- **测试**：覆盖旧格式迁移、V3 元数据往返、锚点/采样/密度、损坏数据保护、项目切换、音符选择同步和撤销标记。
