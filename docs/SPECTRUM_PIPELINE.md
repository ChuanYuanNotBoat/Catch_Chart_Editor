# AE 与主编辑区的频谱

主编辑区通过“视图 → 显示频谱叠加层”开启，默认关闭并保存偏好。频谱位于背景之上、网格和音符之下，不拦截鼠标，不添加波形图。关闭后销毁该层并取消请求，不保留轮询定时器。

## 计算与缓存

- 保留 CCE 的 2048 点 Hann 窗、对数频率轴、双声道 dBFS 与瞬态分析接口。局部页步长由 10ms 缩至约 5ms，频段由 128 增至 192；长页面仍最多 12,000 帧，最长请求 120 秒。
- 5ms 表示相邻分析帧的步长，FFT 窗长和固有频率分辨率保持不变；192 个对数显示频段中的相邻低频段可能覆盖同一 FFT bin。
- FFT 的窗、位反转和旋转因子只初始化一次，频段范围每页预计算。左右实信号打包进入一次复数 FFT，再分别恢复各自功率，避免反相信号抵消。每次调用使用自己的工作缓冲区。
- Ogg Vorbis 使用仓库已有 Xiph 解码库定位到目标采样位置；其他格式继续由 Qt 后台解码。分析窗口额外读取页面两侧上下文，但返回的起点和时长只表示请求区间。
- AE 和主编辑区共用一个最低优先级工作池，将音频按固定 2 秒分块，统一使用精确 5ms 时间网格（包括 44.1kHz）。缓存键按完整路径、大小、修改时间和算法版本识别，与 BPM、偏移、窗口范围及合并/双声道显示无关。不同范围的请求只需补齐缺失块，不重新分析重叠区间。
- 同一块正在处理时，多个使用方订阅同一个任务；取消一个窗口不影响另一个。全部订阅者已取消的排队任务直接跳过；已经开始的小块允许完成并入缓存，旧源结果不入缓存。进程内 LRU 为 48MiB、最多 128 项；磁盘缓存采用版本校验与原子写入，预算 256MiB、最多 1024 个文件，按节流清理。
- 主编辑区保留可见块并预取一个相邻块，历史缓存按 48MiB / 64 块淘汰可见区外数据；AE 保留最多 56 个共享细块和最多 3 个 / 24MiB 的派生分析页。数组、图像与正在执行的任务都共享，不因窗口数量复制双声道 FFT。
- Debug 仅对独立的纯数值 DSP 库启用优化，保留调试符号、Debug CRT 和容器 ABI，其他编辑器代码保留正常 Debug 检查，减少细颗粒频谱在 Debug 下的等待。
- 左右频谱使用索引色图像，主编辑区另用逐频段取最大值的时间金字塔。颜色范围固定，不对单页自动归一化。金字塔在后台准备，缩小时保留短促峰值。

## 更新边界

音频位置始终是原始音频时间，BPM 和 chart offset 只进入显示映射。主编辑区逐 BPM 段映射图像到现有 beat 坐标，直接使用 ChartCanvas 的滚动、翻转与缩放；播放仍由原有时钟和帧确认机制推进。

普通音符修改不使频谱失效；Timing 变更和撤销只更新投影；Resources、音频元数据、切谱以及同一路径文件替换才清理源状态。每个使用方最多一项未完成块请求，旧源/隐藏窗口/关闭开关的回调不能覆盖新视图。AE 与主编辑区的显示状态独立，双声道数据与任务共享。

可见区优先于预取。主编辑区逐块直接绘制，AE 每收到一块就能显示该区间，不必等待整页完成；AE 派生页的最小时长从 12 秒缩至 4 秒，供瞬态分析的完整页也从相同分块拼接。后台在块之间让出工作池，让两个窗口都能推进。后台繁忙且视口已跳出目标范围时取消旧订阅。主编辑区绘制过程中不解码、不分析、不生成整窗频谱图像，也不建立第二套播放定时器；AE 的多块视窗合成在独立后台线程运行，沿用约 15Hz 刷新节流，等待期间保留上一张视窗。

实现仅参考 maV 的可见区优先、分块复用和渐进显示行为；调度、Qt 生命周期、音频分析和缓存代码独立实现，未复制 Emiria 代码。

## 验证

`analysis_spectrum_tests` 检查标定、左右分离、反相、静音、页面上下文、时间原点和取消；`analysis_transient_tests` 保护现有瞬态检测语义。

`ui_spectrum_overlay_tests` 检查缓存共享及失效、真实 WAV/Vorbis 裁切、峰值金字塔、BPM/offset/翻转/缩放、旧回调与隐藏窗口、开关资源释放。`analysis_editor_tests` 另检查 AE 和主编辑区同时启用。

前一版整页管线曾通过 Debug / Release 两种配置的 8 组定向 CTest。下列历史测量也来自该版本，不能作为本次分块管线的实测结果。本次仅做相关构建与定向检查，避免扩大验证范围。

2026-10-18 分块接入：Debug 主程序、频谱算法、叠加层和 AE 测试目标编译通过；`analysis_spectrum_tests`、`ui_spectrum_overlay_tests` 两组通过（合计 1.55 秒），AE 另选分页、旧回调、视窗裁切、多块缺口补齐、绘制缓存、双窗口共存及真实裁切 7 项通过。共享测试确认不同范围订阅重叠块时只生成 1 个块，扩展到 4 秒只补 1 个块，并保持原双声道数组一致。本轮未扩大到全套回归或重复性能矩阵；本机编译器随机退出的临时规避记录在 `TESTING.md`。

独立 DSP 对比入口为 `tools/perf/spectrum_benchmark.cpp`：用相同编译器和优化选项分别链接旧版及当前 `SpectrumAnalysis.cpp`、`TransientAnalysis.cpp`，输出三个样本的中位数和最大耗时。先预热一次，再测量五次。

播放基准增加 `--benchmark-spectrum-overlay`，只在当前基准进程中启用叠加层，不修改已保存偏好；报告记录 `spectrum_overlay` 和 `spectrum_page_ready`。可用 `--benchmark-settings-dir <目录>` 隔离基准设置，`--benchmark-window-size 2560x1440` 指定离屏画布所在窗口大小。

`--benchmark-mute` 同时静音音乐与打击音效，不修改用户音量偏好，也不停止解码、播放时钟、音符调度和绘制；报告的 `muted` 来自实际音乐输出状态。比较开关性能时，应对两组使用相同的静音参数。与同参数关闭状态比较 FPS、paint p95、UI stall 和 skipped refresh。离屏测试不能代替目标显示器上的完整交互验收。

Windows 的新增叠加层测试使用 Qt `minimal` 平台，以避开 `offscreen` 字体后端连续创建普通 ChartCanvas 时也会出现的崩溃；图像像素、时间投影和异步生命周期断言全部保留。Release 的完整 AE 测试和播放基准另使用 `offscreen` 检查实际画布绘制。

## 2026-10-17 本地测量

独立分析对比使用 MSVC 19.51、Release 相同选项，输入为合成单音，耗时单位为 ms。这是本机计算测量，不代表所有音源的加载耗时。

| 输入 | 原频谱中位数 | 新频谱中位数 | 原瞬态中位数 | 新瞬态中位数 |
| --- | ---: | ---: | ---: | ---: |
| 12s / 44.1kHz / mono | 94.25 | 40.86 | 7.63 | 22.05 |
| 12s / 48kHz / stereo | 92.76 | 44.91 | 7.23 | 21.49 |
| 120s / 48kHz / stereo | 932.73 | 228.92 | 72.22 | 109.98 |

前两项的时间帧约翻倍；第三项保持 12,000 帧上限。三项均使用 192 频段。瞬态检测因输入更细而增加工作量，但两阶段中位数之和仍分别下降约 38%、34%、66%。

Qt 6.10.2 / MSVC 19.44 Release 下使用 4,461 音符谱面、60 FPS、3s 预热加 10s 测量：796×796 窗口交错测试三轮，关闭叠加层的 paint p95 为 0.78–0.92ms，开启为 0.93–1.10ms；全部通过现有播放基准，无 UI stall。2560×1440 窗口的单轮关闭/开启分别为 2.92/3.81ms，两组约 60 FPS，均无 UI stall 或丢失显示刷新；开启组确认频谱页已加载。新增图层有有限绘制开销，关闭路径不启动频谱工作或轮询。

追加 `--benchmark-mute` 后的大窗口对比也通过：两组实际 `muted=true`，10s 测量中媒体位置均推进 9,985ms，约 59.99 FPS，无 UI stall 或丢失显示刷新；关闭/开启的 paint p95 为 2.69/4.16ms，开启组 `spectrum_page_ready=true`。
