# BPM 高级编辑

从 **BPM → 高级 BPM 编辑…** 打开独立窗口。窗口为非模态，主编辑区仍可放置、
移动、删除音符及执行撤销；再次点击入口会聚焦已有窗口。

## 曲线与定位

- 纵向为拍点，横向为 BPM。视图跟随主编辑区的滚动、缩放、播放位置和上下翻转。
- 蓝色为谱面实际 BPM 阶梯曲线。点击变速点显示原始拍点三元组及 BPM，并定位；
  中键自由定位。定位不自动开始播放，也不修改谱面。
- 滚轮滚动，Ctrl + 滚轮缩放。曲线窗口中的操作同步主视图。
- 插值预览显示理想曲线、实际写入阶梯和节点。手动测量显示 Start、End 与参考网格。
  预览不替换真实 BPM 或吸附基准。

## 手动测量与插值

工具与现有 Timing 面板共用测量、插值核心，不依赖频谱解码或 AutoTiming 分析。
详细数值规则仍以 [ANALYSIS_EDITOR.md](ANALYSIS_EDITOR.md) 的对应章节为准：

- 测量 Start 使用精确拍点和当前分度；拾取已有变速点保留原三元组。End 是自由音频时间，
  可拖动或输入；拍数默认 1，接受小数及分数。支持复制完整精度 BPM。
- 插值的 BPM 对拍数线性变化，支持拍长、起止拍点和时长三种范围输入。
  默认最大间隔 1 拍、误差严格小于 10 ms；复用积分、局部细分和实际时间缓存漂移校验。
  可在 End 恢复谱面原 BPM，并导出全部节点及误差。
- 应用前统计受影响的音符数量和最大音频时间变化。确认窗也为非模态，默认选择“不应用”。
  保留音符拍点和 offset，使用共享撤销栈的一次 timing-only 操作提交。
- 等待计算或确认时若谱面、参数、音源或工具可见性发生变化，旧结果不能提交。
  修改参数后重新预览；谱面修改后需重新生成插值预览。

## 更新与性能

- 曲线仅在可见时更新，跟随既有主视图信号，不创建播放计时器或音频分析任务。
  实际曲线按纵向像素采样；节点选择保留精确拍点，密集节点的绘制不会无限增长。
- 拍点／时间缓存仅随 Timing、元数据或谱面加载更新，普通音符编辑不重建曲线缓存。
- 插值构建和应用影响统计共用一个最低优先级后台线程。每个插值面板最多一个在途任务，
  额外修改合并为最新请求。后台只读取值快照，不访问界面或控制器。
- 返回结果同时检查请求代次、谱面 revision 和可见性。隐藏、取消或关闭会废弃预览；
  关闭窗口不等待后台任务。导出对话框为非模态，文件原子写入在后台完成。
- 撤销、重做、取消、播放／暂停使用现有 CommandRouter 和用户配置的快捷键。

旧 BPM 颜色控制、Rain 密度、假 BPM 等需求已[废弃归档](archive/BPM_LEGACY_REQUIREMENTS.md)，
本轮不采用其分支、依赖或实现规则。AE/AC 算法优化仍暂缓。
